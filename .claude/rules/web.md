## フロントエンド コーディング規約

- tailwind merge の使用は意図しないマージが起こるので使用禁止
- tailwind variants の slot は複雑になるので基本使用しない
- memo 化はなるべく React Compiler に任せる

### tailwind css

- `space-*`は使用せず、`gap-*`を使う
- `!`（important）による強制上書きは原則禁止。他に手段が無いと確認できた場合のみ、理由をコメントに
  残して使う
- コンポーネントの外側の余白（`m-*`、兄弟との距離のための`p-*`）と、外側から見た
  幅（`w-full`、`max-w-*`など）は、コンポーネント内に持たせず`className`で
  呼び出し側から渡す。

### 表示名

- ユーザー名・プレイヤー名を画面に出すときは必ず`getDisplayName`を通す。
- ただし`Avatar`と`UserLabel`は内部で適用するので、この2つには**生の名前を渡す**。
- フォームの初期値や送信値など「編集対象の値」には使わない。
